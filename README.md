# OpenDraft

OpenDraft is a free, open-source, local-first screenwriting tool.

Project values:

- Fountain is the native screenwriting format.
- No accounts.
- No tracking.
- No analytics.
- No backend.

## Local Development

Install dependencies:

```sh
npm install
```

Start the dev server:

```sh
npm run dev
```

Build for production:

```sh
npm run build
```
